# DrinkingGames
Retro-Trinkspiel im Atari ST-Stil! Ein rundenbasierter Partyhit für bis zu 8 Spieler. Basiert auf einer modular erweiterbaren State-Machine mit chiptune-synthetisierten Sponsoren-Hymnen und 3 animierten Pixel-Art-Schiedsrichtern. Universelle Steuerung (Touch/Gamepad/Tasten). Das ultimative Pass-and-Play-Turnier!
